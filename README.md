# Audio Automation Documentation

This repository is the organization-level documentation home for the Audio Automation platform.

## Structure

- `docs/architecture` - system architecture and technical structure
- `docs/features` - feature-focused documentation
- `docs/reports` - operational and migration reports

## Active Platform Scope

- Core backend: `audio-library-automation-bot`
- Additional service: `audio-silence-service`
- Planned frontend: `audio-frontend`
- Planned CI/CD control: `audio-platform-cicd`
