File Operations — What the system handles
INPUT / UPLOAD
📥 .mp3 — audio files
📥 .png — book cover images
📥 .mp4 — particle overlay video
📥 .torrent — via qBittorrent
📥 JSON — audiobook metadata
📥 Base image — for cover gen
OUTPUT / PRODUCE
📤 .mp3 — compressed / trimmed / concatenated
📤 .png — book covers (N copies)
📤 .mp4 — generated video (partial)
📤 JSON — audiobook metadata, descriptions
📤 Images — DALL-E generated PNGs
EXTERNAL DISTRIBUTE
🌐 Boosty — image+audio posts (Playwright)
🤖 Telegram — audiobook files
🔍 Baza-Knig — catalog scraping
☁️ Firestore — metadata sync (optional)
❌ YouTube — stub only
Feature Flag Quick Reference
app.core.enabled=true → Audio processing + Library CRUD only (safe/minimal mode)
app.core.enabled=false → Everything enabled: Telegram, Boosty, AI, Torrent, Parser, Search
